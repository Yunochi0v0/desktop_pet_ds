## Project purpose（这个项目是做什么的）

Prompt Pet 是一个常驻桌面的「代码精灵」桌宠。它会以透明悬浮球的形式待在屏幕角落，
在你写代码时陪着你；后续阶段它会在你触发时弹出提示气泡，并接入大模型 API，
扮演一个随叫随到的 Prompt 助手。

第一版不做炫技功能，只做一件事：**让一个透明小球稳定地待在桌面上，不挡你干活。**

## Target users（谁会使用它）

- 主要用户：我自己 —— 每天长时间在电脑上写代码 / 做作业的学生开发者。
- 次级用户：同样希望桌面上有个轻量交互入口、但不想被常驻窗口打扰的人。

## Core problem（它解决什么问题）

- 写代码时想问 AI 一个小问题，需要切窗口、开网页、登录，打断心流。
- 常见的桌宠类程序要么挡住桌面操作，要么必须一直开着很大的窗口。
- 需求：**存在感低、随时可用、完全不干扰原有桌面操作。**

## Core features（核心功能有哪些）

按阶段交付，每阶段只做一件事：

| 阶段 | 核心功能 |
| --- | --- |
| Phase 1 | 透明悬浮桌宠窗口：无边框、置顶、不占任务栏、动态鼠标穿透、可拖拽 |
| Phase 2 | 交互弹窗：点击桌宠弹出气泡对话框，可输入文字 |
| Phase 3 | AI 接入：把输入发给大模型 API，把回答显示在气泡里 |

## Non-goals（明确不做哪些事）

- ❌ 不做用户登录 / 账号体系
- ❌ 不做多桌宠、皮肤商店、养成数值系统
- ❌ 不做移动端
- ❌ Phase 1 不实现任何弹窗、输入框、网络请求（本阶段严格只做「框架 + 透明悬浮」）
- ❌ 不做自动更新 / 安装包分发

## Constraints（时间、平台、技术上的限制）

- 课程作业，截止日期在 12 月 4 日前，需要留出报告与截图时间。
- 开发平台：macOS（主要验收环境），代码保持跨平台可运行。
- 技术栈限制：只用 Electron + 原生 HTML / CSS / JS，不引入前端框架
  （项目规模小，框架只会增加复杂度和出错面）。
- 全程遵循「一次只做一个 Phase，验收通过才进下一步」的节奏。

## Technical choices（大致用什么技术来做）

| 选择 | 原因 |
| --- | --- |
| Electron | 唯一能用纯 Web 技术做透明无边框桌面窗口且跨平台的方案 |
| 原生 HTML/CSS/JS | 项目小，不需要 React/Vue，避免额外构建步骤 |
| 全屏透明窗口 + CSS 定位小球 | 比「小窗口跟随鼠标移动」简单，Phase 2 弹窗有足够空间 |
| `setIgnoreMouseEvents(true, { forward: true })` | 官方支持的鼠标穿透方案，且穿透时仍能收到 mousemove |
| preload + contextBridge | 满足 Electron 安全基线（contextIsolation / sandbox），只暴露白名单 IPC |

## Success criteria（怎样算成功）

Phase 1 结束时，下面每一条都能由我本人亲手确认：

1. 启动后桌面出现一个黄色发光的深色圆球，悬浮在屏幕右下角。
2. 球体在上下轻微浮动（待机动画），没有窗口边框、没有标题栏。
3. 任务栏 / Dock 中不出现它的图标。
4. 点击球的**旁边**（透明区域），点的是下面的桌面图标 —— 说明穿透生效。
5. 把鼠标移到球上时球会高亮，此时可以按住拖动它。
6. 拖动时球不会被拖出屏幕可视区域。
7. 其他应用窗口无法盖住它（始终置顶）。
